# ChairOS: Dental Clinic Management

Clinic management for Indian dental practices: patients, appointments, treatments and dental charts, GST billing, inventory, lab orders, CRM, reports, video consults, a patient portal and AI helpers.

Each clinic signs up with its own name and admin login (`/signup`). Its data is kept separate from every other clinic's.

- **Developer guide:** [`CLAUDE.md`](CLAUDE.md) covers the structure, patterns, design system and how to add a feature.
- **Self-hosting:** [`SELF_HOSTING.md`](SELF_HOSTING.md)
- **Stack:** Next.js · TypeScript · Prisma · MySQL · Tailwind · Docker
